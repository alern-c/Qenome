# Qenome 概要

Qenome（キノーム、Query + Genome）は、SQL・索引の変更前後を比較するZig製OSS CLI。名前と言語は決定済み。名称の衝突、採用需要、時間短縮の効果は未検証。

## MVPの目的

ローカルSQLiteのSELECT 1本に対し、利用者が指定したCREATE INDEXの効果を安全に比較する。元DBから整合した隔離コピーを作り、追加前後の実行計画、SQL結果、反復実行時間、DB容量増分を示す。

初期利用者はSQLite / D1 / Tursoを使う個人開発者。最初の試用先は自分のアプリのローカルD1を予定する。実データや録音内容を使わず、スキーマとダミーデータで確認する。

## 対象外と限界

自動索引推薦、SQL自動書換え、GUI、D1/Tursoへの直接接続、本番への変更適用は対象外。JSON出力とCI連携は次フェーズ候補。

ローカルSQLiteの測定は本番D1/Tursoの速度・料金・互換性を保証しない。VM-stepをD1の課金行数に換算しない。SELECT 1本の改善から全体性能や書込負担の改善を断定しない。
